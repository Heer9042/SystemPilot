# Git Workflow

## Branching Model

- `main`: Production-ready release branch.
- `develop`: Integration branch for tested features.
- `feature/<name>`: New feature implementations.
- `fix/<name>`: Bug fixes and performance patches.

## Commit Conventions

Follow Conventional Commits:
- `feat: add GPU VRAM temperature telemetry`
- `fix: correct memory working set release calculation`
- `refactor: extract windows power scheme to windows/power.rs`
- `docs: update setup instructions`
