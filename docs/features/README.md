# SystemPilot Features Reference

This directory contains specifications and documentation for each feature domain in SystemPilot:

- `dashboard.md`: Real-time system health score & overview HUD.
- `memory.md`: RAM & Standby cache cleaner, Working Set trimming.
- `processes.md`: Process inspector, tree explorer, priority booster.
- `cpu.md`: Core topology, frequency scaling, clock & thread monitoring.
- `gpu.md`: Dedicated/Integrated GPU engine load, VRAM, and thermal monitoring.
- `disk.md`: SMART health, read/write I/O throughput, partition manager.
- `network.md`: Bandwidth monitor, active socket connections, latency tester.
- `gaming.md`: Gaming mode optimizer, background throttling, GPU priority.
- `cleanup.md`: Junk file cleaner, temporary files, Windows update cache remover.
- `startup.md`: Startup app manager, boot impact estimation.
- `benchmark.md`: Synthetic CPU/RAM/Disk benchmark runner.
- `security.md`: Windows Defender status, Firewall rules, UAC configuration.
