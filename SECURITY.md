# Security Policy

## Supported Versions

We actively provide security updates for official stable releases of SystemPilot.

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |
| < 0.0.4 | :x:                |

---

## Reporting a Vulnerability

SystemPilot operates with standard user permissions and interacts with Windows system APIs to monitor performance, memory, and hardware telemetry. Security and stability are top priorities.

If you discover a potential security vulnerability within SystemPilot:

1. **Do not disclose the vulnerability in public issues or discussions.**
2. Report the vulnerability privately via **GitHub Security Advisories**:
   `https://github.com/Heer9042/SystemPilot/security/advisories/new`
   *(or email the project security contact at `[SECURITY_CONTACT_EMAIL]` if configured)*.
3. Provide:
   * Description of the vulnerability and its potential impact.
   * Step-by-step reproduction instructions or proof-of-concept.
   * Affected operating system versions (Windows 10 / Windows 11).

### Response Timeline
* **Initial Acknowledgment:** Within 48 hours of receipt.
* **Triage & Status Update:** Within 5 business days.
* **Remediation & Release:** A patch will be tagged and distributed through official GitHub Releases and the In-App Update system.
