# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

SystemPilot runs with native Windows system privileges to monitor performance, processes, and hardware telemetry. Security is of utmost importance.

If you discover a security vulnerability within SystemPilot:
1. **Do not create a public issue.**
2. Report the vulnerability privately by contacting the maintainers or opening a GitHub Security Advisory.
3. Provide a clear description and reproduction steps.

We will acknowledge reports within 48 hours and work on remediation promptly.
